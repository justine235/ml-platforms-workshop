# Workshop deck: how it is built and how to change it

**Machine learning on Microsoft: Fabric, Azure Machine Learning and Foundry.** A full-day workshop for data scientists and data engineers. All text is in English.

The deck is generated by Python (python-pptx) from plain source files, so every slide is a **native, editable PowerPoint slide**: real text boxes, shapes, connectors, tables and small PNG icons. There are no whole-slide images and no live-portal screenshots.

## What you get

| File | What it is |
|---|---|
| `ml-platforms-workshop.pptx` | The full-day deck: **105 slides** (94 main slides + 11 appendix slides). |
| `ml-platforms-workshop-halfday.pptx` | The same 105 slides with the optional ones **hidden** (not deleted): 51 core slides, about 216 minutes. Unhide a slide in PowerPoint to bring it back. |
| `slide-index.md` | One row per slide: id, layout, minutes, core or optional, headline. |
| `build-report.md` | Minutes per part, problems, layout warnings, numbers to double-check. |

Every slide has a title that says the point, an eyebrow with its part, and **speaker notes** you can read aloud. 54 slides are optional: use them when time allows, skip them when it does not.

## Speaker-note conventions

Every note starts with a header such as `[P1.3 · ~4 min · CORE]` (slide id, minutes, core or optional). Then the text to say, followed by labelled lines when they apply:

- `SOURCE:` where the claim comes from (a fact sheet, a Microsoft Learn page and its date, or a demo kit file).
- `DEMO:` what to run or show, and which kit file holds the steps.
- `WATCH OUT:` a trap, a preview feature or a limit.
- `IF SHORT ON TIME:` what to cut.
- `TRANSITION:` the sentence that leads to the next slide.
- `VERIFY:` a label or number to re-check in the live portal before Friday (the list is `..\VERIFY-BEFORE-FRIDAY.md`).
- `ASK:` a question for the room.

## Rebuild the deck

You need Windows with Python 3.11 or later and the fonts Trebuchet MS, Segoe UI and Consolas (the build measures text with the TTF files in `C:\Windows\Fonts`; on another system, copy the fonts and change the path in `deck_core.py`).

```powershell
cd 01-slides
python -m pip install python-pptx pillow lxml
python build_deck.py                 # strict build: writes the files above into this folder
python build_deck.py --out out\check # same, into another folder
python build_deck.py --draft         # tolerate missing modules while authoring
```

A strict build fails (exit code 1) if a slide id is missing or out of order, a part is more than 3 minutes off its agenda, the core path is off its target, a slide has fewer than 40 words of speaker notes, or the text contains a placeholder or a broken character. It lists, without failing, the numbers of four digits or more that are not in the reference run (`build-report.md`): check those by hand. It also lints the diagrams: an edge that crosses a node, or text that does not fit its node, is reported.

## Change a slide

1. Find it in `slide-index.md`. The module name follows the part: `content_open.py` (O1 to O5), `content_p1.py`, `content_p2.py`, `content_p3.py` (P3.0 to P3.14, Fabric), `content_p3b.py` (P3.15 to P3.25: Azure ML, the bridge from Fabric, comparison, lab, recap), `content_p4.py`, `content_close.py` (C1 to C4 and A0 to A10).
2. Edit the Python call for that slide. `CONTENT-API.md` lists every layout (cards, flow, architecture diagram, table, code, demo steps, takeaway bar) and its arguments.
3. Rebuild just that module: `python devbuild.py content_p2` (output in `out\dev\content_p2`).
4. Numbers come from `facts.py`, which reads `..\02-demo-data\reference_out\ground_truth.json`. Use `F.some_name` and `n(...)` instead of typing a figure.

## Check the rendering (Windows and PowerPoint only)

The checks open the file read-only in the installed PowerPoint through COM. Run them one after the other, never in parallel.

```powershell
$pptx = "$PWD\ml-platforms-workshop.pptx"
.\qa_deck.ps1     -Pptx $pptx -OutJson "$PWD\out\qa.json"     # text that overflows or is clipped
.\render_deck.ps1 -Pptx $pptx -OutDir  "$PWD\out\render"      # one PNG per slide
python contact_sheet.py out\render out\sheet --cols 4 --rows 3 # overview sheets
python dump_text.py ml-platforms-workshop.pptx out\text.md     # all text and notes, for proofreading
```

`check.ps1 content_p2` does build, QA, render and contact sheets for one module. These checks do not catch everything: they missed overlaps between a table and a source line and a few words that broke in the middle of a token, which were found by looking at every rendered slide. Look at the render before you trust a change.

## Icons and fonts

- `assets\icons` holds 725 small PNG icons: generic outline icons (Lucide style, ISC licence) in six colours, and official Microsoft product icons for named services. Provenance and licences: `assets\icons\PROVENANCE.md`. List the names with `python icons.py`.
- Palette: white, blue and amber, with soft tints for state. Fonts: Trebuchet MS for titles, Segoe UI for body text, Consolas for code.

## What this deck does not do

- It is static. The platform labels, menu names and preview features were checked against Microsoft Learn on 2026-10-18 and 19, not in a live tenant. Re-read the portal banners on Thursday and Friday morning, and use `..\VERIFY-BEFORE-FRIDAY.md`.
- The build has been checked with PowerPoint on Windows only. It has not been opened in Keynote, Google Slides or LibreOffice.
- `slide-plan.md` is the approved plan the deck was built from.
